# Промежуточный статус проекта EventHub

Дата: 2026-05-05

## Общее состояние

EventHub уже имеет рабочую backend-основу для университетской платформы мероприятий: пользователи, роли, организации, мероприятия, регистрации, посещаемость, баллы и награды. Backend выглядит основным готовым слоем проекта, а frontend находится на этапе подключения к готовым API и построения ролевых кабинетов.

## Что сделано

### Backend

- Поднят Spring Boot backend на Kotlin:
    - Spring Boot 4.0.6;
    - Java 21;
    - Maven;
    - PostgreSQL;
    - Spring Security;
    - Spring Data JPA;
    - Flyway;
    - OpenAPI/Swagger.
- Настроена база данных:
    - `application.yaml` с PostgreSQL, Flyway и `ddl-auto: validate`;
    - `docker-compose.yaml` с PostgreSQL;
    - Flyway-миграции `V1`-`V12`.
- Реализована доменная модель:
    - пользователи;
    - роли;
    - связи пользователь-роль;
    - организации;
    - менеджеры организаций;
    - мероприятия;
    - регистрации на мероприятия;
    - посещаемость;
    - транзакции баллов;
    - награды;
    - покупки наград.
- Реализована авторизация:
    - регистрация;
    - вход;
    - получение текущего пользователя;
    - JWT access token;
    - BCrypt-хеширование паролей;
    - stateless security;
    - кастомные JSON-ответы для 401/403.
- Реализована ролевая модель доступа:
    - `STUDENT`;
    - `ORG_MANAGER`;
    - `ADMIN`;
    - активная роль передается через `X-Active-Role`;
    - backend проверяет активную роль через `ActiveRoleGuard`.
- Реализованы backend API:
    - `/api/auth/register`;
    - `/api/auth/login`;
    - `/api/auth/me`;
    - `/api/users/{id}`;
    - admin API для организаций;
    - admin API для наград;
    - manager API для мероприятий и посещаемости;
    - student API для мероприятий, регистраций, баллов и наград.
- Реализована бизнес-логика:
    - регистрация пользователя как студента;
    - назначение менеджера организации;
    - создание и публикация мероприятий менеджером;
    - просмотр опубликованных мероприятий студентом;
    - регистрация студента на мероприятие;
    - учет вместимости мероприятия;
    - отметка посещаемости менеджером;
    - начисление баллов за посещение;
    - просмотр баланса и истории баллов;
    - покупка наград за баллы;
    - выдача купленных наград администратором.
- Добавлены DTO и mapper-функции для основных сущностей.
- Добавлен общий слой ошибок:
    - `BadRequestException`;
    - `ForbiddenException`;
    - `NotFoundException`;
    - `GlobalExceptionHandler`;
    - `ErrorResponse`.

### Frontend

- Поднят Vue frontend:
    - Vue 3;
    - Vite;
    - TypeScript;
    - Pinia;
    - Vue Router;
    - Tailwind CSS;
    - Nuxt UI.
- Есть базовые публичные страницы:
    - home;
    - login;
    - register.
- Добавлена новая auth-инфраструктура:
    - Axios HTTP client;
    - auth API client;
    - auth store;
    - role store;
    - типы пользователя, ролей и auth DTO.
- HTTP client уже умеет добавлять:
    - `Authorization: Bearer <token>`;
    - `X-Active-Role`.
- Настроен Vite proxy:
    - `/api -> http://localhost:8080`.
- Добавлен ролевой роутинг:
    - `/select-role`;
    - `/student`;
    - `/manager`;
    - `/admin`.
- Добавлены route guards:
    - проверка авторизации;
    - загрузка текущего пользователя;
    - проверка активной роли;
    - редирект на выбор роли.
- Добавлена страница выбора роли.
- Добавлены стартовые страницы кабинетов:
    - студент;
    - менеджер организации;
    - администратор.
